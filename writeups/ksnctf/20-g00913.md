## 概要

円周率の連続する桁から最初の10桁素数を探す問題。整数部の3から数えて5926535897 が最初。

## 解析

問題文は FLAG_Q20_{πの連続桁に現れる最初の10桁の素数}。添付なし。πを2000桁生成し(Machin公式, 整数演算)、先頭から10桁の窓を1桁ずつずらしてMiller-Rabinで素数判定した。窓は整数部の "3" を含めて数える(位置4から始まる 5926535897)。

## 解法

```python
# 20-pi.py 抜粋
d = pi_digits(2000)   # "314159265358979..."
for i in range(len(d)-10):
    if is_prime(int(d[i:i+10])):
        print(i, d[i:i+10]); break
# -> 4 5926535897
```
