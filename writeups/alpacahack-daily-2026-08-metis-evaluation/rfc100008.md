## 概要

Solved AlpacaHack Daily RFC100008 by discovering the per-instance HTTP method and invoking its route. The official browser marked the challenge Solved.

## 解析

The statement points to a custom HTTP method. The distribution shows that each app process creates METHOD with secrets.token_hex(8).upper(), registers only that method on /rfc100008, and returns the flag from the handler. Flask's automatic OPTIONS response exposes the current method in Allow. A bounded OPTIONS request to the single user-authorized instance returned OPTIONS plus a 16-character uppercase hexadecimal method; no guesses or broad method scans were needed.

## 解法

Request OPTIONS /rfc100008 on the exact instance created by the official Spawn Challenge Server control. Read the custom token from the Allow header. Send one request using that exact method to /rfc100008 through the METIS-granted endpoint, capture the response privately, and submit the returned value once through the logged-in official browser. Confirm the official Solved state.

## 学び・再利用できる手法

For Flask routes registered with a dynamic method list, the automatic OPTIONS response can reveal the methods accepted by that route. Keep discovery to the authorized instance, use the exact route, and verify through the official browser. Do not treat status codes or local parsing as a solve verdict.

- **Discover per-instance Flask methods through OPTIONS**（web）: Use a route's automatic OPTIONS response to learn its current Allow-method set, then call only the explicitly registered method on the exact authorized route.
