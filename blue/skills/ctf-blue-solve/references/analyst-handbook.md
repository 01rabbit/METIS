# Evidence-based defensive exercise workflow

The owner receives instructions, reports findings and controls authorized submissions.
Workers analyze independent questions; shared attempts, browser state and hosts are leased.
Use supplied artifacts and the authorized exercise interface, not solution catalogs.

## Scope and intake

Read the brief, inventory, question wording and answer format. Offline evidence, a live
question service and public-source research require different observations. Missing data
justifies an acquisition request, not an exploit or guessed answer. A descriptor naming a
server or third-party asset does not authorize access. Continue independent offline work
when an interface is unavailable.

## Meaning and representation

Resolve the requested entity before formatting: hostname versus FQDN, key versus value,
executable versus command, original filename versus local copy, family versus hash,
activity start versus indexing time, observed versus derived URL. Causal questions need
evidence of effects, not merely the next chronological event.

Separate source bytes, decoded value and display representation. Decode HTML entities, JSON
escaping and source-language string syntax only at the layer that introduced them. Preserve
evidence for that layer; avoid blanket lowercasing or punctuation changes.

For compound answers verify count, order, separator and relation. Retain internal UTC and
source precision, then render the requested timezone. Check version suffixes and extensions.
Placeholders are not evidence; explicit format instructions govern independently proven values.

For screenshots, ASCII art and OCR, reconstruct from stable glyphs/source rendering where
possible and verify against pixels. Similar-looking characters are uncertainty. Review both
PDF text and rendered pages when extraction loses layout.

Document information an encoding destroys, such as case or spacing. Rank only supported
interpretations and never enumerate arbitrary answer variants.

## Provenance and reconciliation

A typed worker answer points to evidence; re-extract it from the exact artifact and coordinate.
Require digest, method, limits and confidence. Reject stale results, placeholders, labels,
empty strings and copied prompt examples. Some answers exist in a decoded local artifact
rather than a network transcript; choose the channel appropriate to the claim.

Replay consequential derivations independently. Preserve disagreement instead of voting.
A familiar prefix or plausible string alone is insufficient.

## Submissions and feedback

Before a write, verify the exact value, evidence, requested representation, current question
and scoped user/owner authority. Serialize submissions through the owner or a specifically
granted worker. Record time, opaque answer reference and outcome privately. Keep answer
literals, credentials and case catalogs out of Git.

Check the current interface's length and encoding contract before an authorized submission:
a limit may count bytes, Unicode code points, UTF-16 code units or displayed graphemes. Measure
the prepared value in the specified unit after the required encoding; do not reuse another
interface's bound or invent an abbreviated answer.

Compare the final UI/request value with the intended value, then compare any returned or
stored value after decoding only its documented representation. Silent truncation or altered
text is an interface discrepancy. If the receiving system exposes no value, record that
verification gap rather than assuming equality or repeating an uncertain submission.

Distinguish not-dispatched, transport-failed, permission-denied, pending, accepted and rejected.
Observe completion or attempt-state change; clicking a button does not prove delivery.
Prevent duplicate submission after reconnects.

Rejection alone does not refute a fact. Diagnose source, scope, transport and representation
before spending another attempt. An acceptance applies to that question, not a guessed
universal matcher. Do not probe validators for hidden answers or spray format variants.
Keep a shared finite attempt budget.

## Time and closure

Prioritize available evidence and falsifiable paths; time-box uncertain questions. Other
analysts' failures, no solves or unreachable services do not prove a broken task. An
impossibility claim needs a structural explanation tied to the artifact's information.

After confirmation, stop redundant workers/monitors, reconcile usage, release leases and
close the case. If unresolved, state the best supported interpretation, exact gap and next
evidence needed. Promote only lessons independent of the exercise identity.
