## 運用上の注意

- **Codex CLI の版:** 試験済みの版（0.166.0、0.169.0）以外では、ドライバは起動を拒否する。自動更新の後は `metis agent codex-probe --ping --allow-untested-codex` で全項目が合格するのを確かめてから、`codex_isolation.TESTED_CODEX_VERSIONS` に版を追加する。
- **`--cyber-access-program`:** 既定では指定しない。`gpt-daybreak-blue-latest` は `daybreak_blue` の指定を要件とする（standard では 400）。指定するかどうかは運用者の判断。
- **答え保管庫:** `~/.local/share/metis/answers.json`（0600）。テストは一時的な保管庫を使う（`tests/conftest.py`）。
- **配布データ:** ksnctf の配布ファイルは Git に入れていない。実データのテストは環境変数で有効にする（`METIS_TEST_KSNCTF33_PCAP`、`METIS_TEST_KSNCTF39_ZIP`、網羅的な攻撃は `METIS_TEST_SLOW=1`）。
- **評価:** writeup のある問題は practice（`writeups/EVALUATION_SPLIT.json`）。独立評価には writeup の無い問題を使う。現時点で該当する ksnctf の問題は #39 だけ。
- **解決率:** これまで 0/3（#33 は回帰、#39 は 2 回）。止まった原因は、METIS の外にある認証要件（#24）と、計算量の大きい攻撃が未実装であること（#28）。
